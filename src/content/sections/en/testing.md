Working and correct are two different things. An app that responds when you click can still be wrong exactly where it matters: when the network drops, when two people act at once, when a list is empty, when the text is not ASCII.

This topic collects posts about software testing — not theory, but how to write a test case, which layer to test at, how to prioritise by risk, and how to make verification run automatically on every change.
